# Gatherly — Event Invite MVP

מערכת הזמנות ואישורי הגעה בעברית, עם ממשק מארגן ושכבה חברתית אופציונלית.

## מה כלול

- עמוד אירוע ציבורי ורספונסיבי
- Dashboard למארגן
- רשימת מוזמנים עם קישורים אישיים
- הוספת מוזמן חדש
- RSVP: מגיע / אולי / לא מגיע
- מספר אורחים, רגישויות והודעה למארח
- פרופיל ציבורי אופציונלי עם הסכמה מפורשת
- עמוד משתתפים ציבוריים
- שיתוף דרך מנגנון השיתוף של הטלפון
- מרכז הודעות עם פילוח והדמיית שליחה
- שמירת נתונים מקומית בקובץ JSON

## הרצה

```bash
npm install
npm run dev
```

פתחו: `http://localhost:3000`

מסך מנהל: `http://localhost:3000/admin`

## נתוני הדגמה

הנתונים נשמרים ב־`data/db.json`. ניתן למחוק או לערוך אותם ידנית.

## מגבלת גרסת ה־MVP

האחסון מבוסס קובץ מקומי ולכן מיועד להדגמה או לשרת Node יחיד. לפריסה אמיתית ב־Vercel יש להחליף את `lib/db.ts` ב־PostgreSQL/Supabase. מרכז ההודעות מדמה שליחה בלבד; חיבור אמיתי דורש ספק WhatsApp Business, SMS או אימייל.

## הפעלה מהירה ב־Windows

לחיצה כפולה על `START_WINDOWS.bat` תתקין את החבילות במקרה הצורך, תפתח את הדפדפן ותפעיל את המערכת.

## איפוס נתוני ההדגמה

```bash
npm run reset
```
